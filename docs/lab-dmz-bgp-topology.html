Lab topology: inside, DMZ and outside with eBGP

SJB-OS (AS 65244) peers with the upstream router (AS 65534) on outside and announces only the DMZ. Inside stays private and leaves NATed; the DMZ is routed by its real addresses. Config: examples/lab-dmz-bgp.yaml.

NAT: inside-out masquerades 192.168.150.0/24 leaving on outside. The DMZ is not NATed.

Before you load it

  • Leave the OVA's outside_gateway empty: the default route comes from BGP. Deploy (or keep) the OVA's mgmt settings: mgmt_ip 192.168.1.75/24, mgmt_gateway 192.168.1.1. The config never changes management.
  • ESXi: set the inside adapter's port group to VLAN 4095 so VLANs 150 and 151 arrive tagged.
  • Upstream router: peer 192.168.149.254 (AS 65244), send it a default route (0.0.0.0/0), and reach 192.168.151.0/24 by the route it learns.
  • In the CLI: load, paste the file, then commit -confirm 5m and confirm once BGP is up (show bgp).
